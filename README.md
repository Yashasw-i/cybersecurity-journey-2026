## Goal

My goal is to build a solid, job-ready foundation in cybersecurity through consistent study, hands-on labs, practical projects, and honest public notes. I’ll focus on skills I can explain and demonstrate, while practicing only in authorized labs and environments.

By the end of this journey, I aim to be able to:

- Build practical skills in networking, Linux, Python, security monitoring, vulnerability assessment, and incident response.
- Prepare for an entry-level SOC analyst or junior cybersecurity analyst role.
- Complete a public portfolio of hands-on labs, security tools, investigation write-ups, and a final capstone project.
